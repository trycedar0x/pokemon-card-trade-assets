# Comet Fox demo card metadata

Public, original sample artwork and metadata for a **Solana devnet-only** card-trading demonstration. No wallet credentials, program binaries, or real-money assets are published here.

- Metadata: `https://trycedar0x.github.io/pokemon-card-trade-assets/demo/comet-fox.json`
- Artwork: `https://trycedar0x.github.io/pokemon-card-trade-assets/demo/comet-fox.svg`

Publishing these files does not mint a card or enable trading. Verify the published bytes against the hashes generated by `scripts/prepare-card-metadata.mjs` in the private application repository before any mint.
